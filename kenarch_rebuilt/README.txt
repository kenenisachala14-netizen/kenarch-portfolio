KENARCH — Architecture & Spatial Design Portfolio

HOW TO VIEW
1. Extract this folder from the ZIP.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. Click a project card to open its own full-page project viewer. Use the branch tabs to explore the overview, visual gallery, design approach and contribution notes.
4. Click any image to enlarge it. Press Escape or use the back button to close project views.

HOW TO DEPLOY
Upload the contents of this folder to Netlify Drop, GitHub Pages, Cloudflare Pages or any static website host. No build step is required. Internet access is needed for the hosted Google Fonts; the rest of the site and images are local files.

CONTENT NOTES
- Images are cropped from the supplied portfolio and internship design sheets into separate visual assets.
- Project details are based on the supplied portfolio text. Where internship project names or facts were not explicit, descriptive working titles are used and the missing facts are not invented.
- Internship contribution is described as rendering, interior design and finishing, as supplied by the portfolio owner.
- The certificate page is a visual reference crop; replace it with a high-resolution original certificate image if you want it readable at full size.
